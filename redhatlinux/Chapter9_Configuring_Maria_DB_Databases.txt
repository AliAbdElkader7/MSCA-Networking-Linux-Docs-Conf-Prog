- MariaDB is a relational database.
- Relational databases are a common way to store information for applications.
- Appache for example can get its information from a database.
- Logging for example can write its information to a database.
- Databases organize data in a set of tables.
- In a table, a raw represents a record.
- In a record, a column represents an attribute of that record.
- MariaDB is a community branch of MySQL.
- PostgreSQL is another open source database
